# SalvaOps: hoja de ruta de documentación

Propuesta para mantener una presentación útil y verificable. No representa un calendario de desarrollo ni certifica funciones disponibles.

## Punto de partida

Base operativa V1 · evolución continua.

## Próximos entregables públicos

- Definir un formato genérico de evidencia sin credenciales.
- Documentar estados de ejecución, límites y decisiones humanas.
- Revisar cómo una tarea conecta objetivo, restricciones, resultado y validación.

## Criterios de aceptación

- La evidencia distingue éxito, fallo y bloqueo sin ocultar limitaciones.
- Acciones que requieren aprobación conservan una referencia verificable a esa decisión.
- Ejemplos y registros públicos no exponen credenciales ni datos de proyectos privados.
- Enlaces locales, SVG y JSON pasan validación antes de publicación.
- Capturas o demostraciones solo se incorporan si tienen autorización de publicación.

## Actualización de estado

Para cambiar el estado público: describir qué cambió, aportar una referencia revisable, indicar limitaciones y obtener validación del responsable del producto. Evitar convertir planes en afirmaciones de resultados.
