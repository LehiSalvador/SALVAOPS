# SalvaOps: contexto y alcance

SalvaOps nació como un workspace local para Windows que reúne proyectos, contexto, documentación, terminales y herramientas de desarrollo asistido por IA. Evoluciona hacia una capa de orquestación y gobierno de agentes.

## Estado documentado

Base operativa V1 · evolución continua. Existe una **base operativa V1**. La orquestación y gobierno de agentes continúan evolucionando. Este repositorio reúne la presentación pública, propósito y alcance del proyecto.

Lehi Salvador — definición de producto y arquitectura. El objetivo es expresar qué debe construirse y sus restricciones, mientras herramientas y agentes especializados resuelven ejecución con contexto y evidencia.

Esta documentación amplía la información proporcionada por el responsable del producto. Los criterios y siguientes pasos de la hoja de ruta son propuestas de documentación pública; no compromisos de entrega ni capacidades adicionales implementadas.

## Flujo de referencia

1. Objetivo y restricciones.
2. Contexto del proyecto.
3. Orquestación y tareas.
4. Ejecución por agentes.
5. Evidencia.
6. Aprobación cuando corresponde.
7. Auditoría.

El flujo describe el contexto del producto. No define una API, integración ni procedimiento productivo listo para ejecutar.

## Vocabulario

| Concepto | Significado en este contexto |
| --- | --- |
| Proyecto | Contexto de trabajo con documentación y restricciones. |
| Agente | Ejecutor especializado coordinado para una tarea. |
| Skill | Instrucciones reutilizables para una capacidad concreta. |
| MCP | Interfaz de integración con herramientas y servicios. |
| Evidencia | Resultado verificable de una ejecución. |
| Aprobación | Decisión humana cuando una acción lo requiere. |
| Auditoría | Registro de decisiones, acciones y resultados para revisión. |

## Límites de publicación

- Existe una base operativa V1; la capa de orquestación y gobierno sigue evolucionando.
- Este repositorio presenta el producto y puede incluir contratos genéricos propuestos, no el workspace privado.
- Credenciales, logs privados, rutas locales y acceso a integraciones quedan fuera de la presentación pública.

Los sistemas reales y su infraestructura se administran por separado. Este repositorio no contiene instrucciones para acceder a clientes o desplegar aplicaciones.
